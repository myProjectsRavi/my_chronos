# Support

CHRONOS is community-maintained open-source software. There is no guaranteed response time or support contract.

After source publication:

- use GitHub Issues for reproducible bugs and focused feature requests;
- use [SECURITY.md](SECURITY.md) for vulnerabilities;
- include version/commit, environment, reproduction steps, expected behavior, and relevant sanitized logs;
- remove credentials, personal data, customer data, private repository contents, and local filesystem identifiers before posting.

Pre-release questions should stay focused on the public repository state and documentation until the certified source snapshot is published.
