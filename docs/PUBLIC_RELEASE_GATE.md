# CHRONOS Public Release Gate

This document is the public contract for publishing the CHRONOS implementation into this clean Git lineage.

The source snapshot must **not** be imported until every mandatory gate below is satisfied with evidence. Unavailable checks are not treated as passing checks.

## 1. Source and privacy

- [ ] No credentials, API keys, tokens, passwords, private keys, or secret material in the source snapshot.
- [ ] No personal email addresses or unintended personal identifiers.
- [ ] No customer/employer-confidential material.
- [ ] No private architecture or planning notes that are not intentionally open source.
- [ ] No proprietary datasets, model weights, local databases, snapshots, backups, identity files, or runtime repository data.
- [ ] License compatibility reviewed for source and bundled assets.

## 2. Repository lineage

- [x] Public repository created without importing the private development Git history.
- [x] Initialization commits use a GitHub noreply identity.
- [x] No inherited tags, releases, stale branches, or historical pull-request refs.
- [x] Full-history secret/privacy scanner runs against every reachable owned ref.
- [ ] Final source-import commit passes the full-history scanner.
- [ ] Deliberate final audit includes any stored public PR-head refs that exist at release time.

## 3. Security and correctness

- [ ] Complete Python test suite passes with the required coverage threshold.
- [ ] Security-focused tests pass.
- [ ] Ruff, mypy, Bandit, and dependency vulnerability audit pass on the final source state.
- [ ] CodeQL passes on the final source state.
- [ ] Network/authentication boundaries receive final adversarial verification.
- [ ] Cryptographic signing, verification, identity, and encryption fail-closed behavior pass final verification.
- [ ] Snapshot/backup integrity and path-containment tests pass.
- [ ] Actual GraphQL parser/ASGI runtime is exercised, not only resolver-unit contracts.

## 4. Multi-language and packaging

- [ ] Rust dependency graph is generated by Cargo; tests and `clippy -D warnings` pass with the final lock state.
- [ ] TypeScript lockfile is generated by npm; clean install, build, and Vitest pass.
- [ ] Go formatting, tests, and vet pass.
- [ ] Docker image builds and receives a runtime smoke test.
- [ ] Package versions and release metadata are synchronized intentionally.

## 5. Performance claims

- [ ] Release-scale benchmark matrix is executed at the documented target sizes.
- [ ] p50/p95/p99, recall/accuracy where applicable, concurrency, memory, CPU, and disk evidence are recorded.
- [ ] README and release notes contain no performance claim stronger than the measured evidence.

## 6. GitHub repository settings

These are platform settings and must be verified in GitHub before source publication:

- [ ] Add a concise repository description and relevant topics.
- [ ] Enable GitHub Private vulnerability reporting.
- [ ] Protect `main` with a ruleset/branch protection requiring pull requests and required checks.
- [ ] Prevent force pushes and branch deletion on protected `main`.
- [ ] Require the Public Safety check and final project CI checks before merge.
- [ ] Enable automatic deletion of merged feature branches.
- [ ] Enable update-branch support for pull requests.
- [ ] Choose and document the intended merge strategy; avoid unnecessary merge-history noise.
- [ ] Disable unused Wiki/Projects surfaces unless the project intentionally uses them.
- [ ] Verify Dependabot/security-alert/code-scanning settings after dependencies are published.

## 7. Final exposure review

Immediately before source publication:

1. inspect every tracked file in the snapshot;
2. run the full-history/all-owned-ref safety workflow;
3. include stored PR-head refs in the deliberate final audit;
4. verify branches, tags, releases, Actions artifacts, and repository settings;
5. verify public documentation links and security-reporting path;
6. issue a final **PUBLIC GO / NO-GO** decision from evidence.

A release is **NO-GO** if any mandatory item is unresolved, failed, or merely assumed.
